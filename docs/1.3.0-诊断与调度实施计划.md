## 第一批：可配置工单诊断基础

已实现：

- 复用 `Issue.script_version`、`Issue.log_snapshot`，创建工单时保存实际执行版本及服务端已有日志的快照。
- 日志最多读取末尾 64 KiB，输出再限制到 64 KiB、末尾 500 行附近（截断提示另计）。首个不完整行被丢弃，单行超长日志可能整行省略。
- 原日志删除后仍可读取快照；创建时没有日志的空快照，不会被后来新增的日志替换。
- 老工单缺少快照时继续读取原日志，但也应用大小限制和当前脱敏策略。
- 诊断参数限制原文大小和嵌套深度；无效历史 JSON 返回省略提示，不原样回传。
- 工单摘要及处理说明应用摘要策略；审计只记录动作和配置字段名称，不记录工单正文或配置值。
- 新增 `0006_diagnostic_policy`，在全局设置单例中保存配置；默认配置安全开启，存储损坏时回退默认保护。保存时通过条件更新拒绝覆盖并发变更。

### 脱敏配置接口

管理员通过 `GET /api/settings/diagnostics` 查看、`PUT /api/settings/diagnostics` 保存。普通用户和开发者不能修改；创建工单的请求不能携带覆盖策略的字段。

默认配置：

```json
{
  "enabled": true,
  "redact_logs": true,
  "redact_params": true,
  "redact_summary": true,
  "custom_sensitive_fields": []
}
```

- `enabled`：总开关。
- `redact_logs`：工单日志快照和兼容日志读取。
- `redact_params`：工单接口返回的运行参数，不修改执行参数本身。
- `redact_summary`：工单标题、描述、执行错误和处理说明。
- `custom_sensitive_fields`：附加敏感字段名称，忽略大小写、按字面名称匹配，不执行用户正则；最多 50 个，每个最长 64 字符。
- PUT 是完整策略替换；省略字段使用上述默认值。关闭已有保护或移除自定义敏感字段时，须在请求中额外提供 `acknowledge_risk: true`，否则返回 409。该确认字段不保存。

开关独立：例如关闭参数脱敏不会自动关闭日志脱敏。访问权限、日志大小上限和参数复杂度限制不受开关影响。

### 已知边界

- **管理员配置界面尚未接入**，目前是服务端 API 和测试基础。
- 常见规则覆盖密码类字段、认证头、Cookie、URL 用户信息及查询参数、私钥块，以及已知敏感参数值；不能识别所有任意业务秘密或编码变体。
- 自定义字段不是任意文本替换规则，也不是 JSON 路径表达式。
- 已脱敏并落库的日志／描述无法通过关闭开关还原。
- 关闭保护期间保存的原文快照，在重新开启后会按当前策略脱敏返回，但原文仍可能存在数据库中。历史原文清理与保留策略还需另行实现，重新开启不等于擦除历史数据。
- 本批没有采集客户端文件或应用日志，没有更改一般执行日志和执行参数接口；完整诊断边界将在后续批次统一接入。
- 执行版本及日志已固定；参数和错误摘要目前仍从关联执行记录读取，完整诊断快照及采集状态尚待补齐。
