# AutoScript Hub 1.2.0

本版本重点完善团队权限隔离、执行结果提醒和客户端更新体验。

## 主要更新

- 增加人员分组，用户和脚本均可归属多个分组。
- 脚本市场、详情、下载、安装、执行、历史、日志、工单和 Dashboard 均由服务端强制实施分组权限。
- 升级时自动建立默认分组，保持已有用户和脚本的可见性。
- 增加脚本执行成功、失败、取消以及执行前失败的 Windows 桌面通知。
- 增加内置更新说明页面和重要更新首次运行提醒，可在本机默认隐藏。
- 客户端默认优先使用 Gitee 更新源，GitHub 自动回退；所有来源继续验证 Ed25519 签名、文件长度和 SHA-256。
- 修复用户管理表格分组文字纵向换行、操作列拥挤，以及旧服务器下基础用户编辑被整体禁用的问题。

## 服务端升级

本版本包含数据库迁移 `0004_grouped_marketplace`。请先备份数据，再升级服务端；就绪检查中的 `database`、`data_dir` 和 `migration` 必须全部为 `ok`。

推荐使用仓库内置的一键远程升级流程：

```bash
python ops/server/remote_upgrade.py --version 1.2.0
```

详细说明见 `docs/0.9-deployment-runbook.md`。
