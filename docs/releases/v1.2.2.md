# AutoScript Hub 1.2.2

本版本重点解决客户端冷更新可靠性，并修复操作审计列表为空的问题。

## 客户端更新

- 检查更新与下载安装彻底分离，仅在用户确认后下载大文件。
- 持久化保存已验证的签名清单，刷新或重启客户端后无需重复检查同一版本。
- 更新源暂时不可用时保留已发现版本，后台检查仍可替换为更高版本。
- 检查更新不再沿用本地 API 的 10 秒超时。
- Gitee 提供 2 MiB 安装包分卷，客户端支持流式下载、有限重试、安全断点续传和逐卷 SHA-256 校验。
- 分卷合并后再次校验完整安装包长度及 SHA-256，失败时自动回退 GitHub 完整安装包。
- 发布流程会在公开后匿名下载所有 Gitee 分卷，重建并校验完整安装包。
- 安装继续采用独立更新器静默执行，并保留启动失败自动回滚。

## 操作审计

- 修复审计接口响应模型错误导致数据库存在记录但接口返回 500、页面显示为空的问题。
- 审计日志加载失败时会显示明确错误提示。

## 其他修复

- 修复 Windows 维护电脑发起远程服务器升级时的 Shell 换行与标准输入兼容问题。

## 后续计划

热更新架构已记录至 `docs/TODO.md`，本版本不引入热更新，优先保证冷更新链路稳定。
