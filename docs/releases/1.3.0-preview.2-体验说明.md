# 1.3.0 Preview 2 体验说明

## 定位

- 版本：`1.3.0-preview.2`，独立 Preview 安装家族；构建渠道字段仍为 `beta`，不代表与正式安装共用数据。
- 源码分支：`preview/1.3.0-preview.2`。
- 正式版本仍为 `v1.2.4`；本次不合并 main、不创建正式 Tag 或 GitHub Release，不自动升级服务端。

## 相比 Preview 1

- 登录页和侧栏支持简体中文 / English 切换，覆盖 React 主界面的固定文字和日期控件。
- 语言切换保留设置和脚本表单，不修改 API、脚本参数 key、执行状态、权限或时区。
- 改善英文按钮、矮窗口侧栏和固定表格列的显示。
- 新增 English README，并整理中文说明、下载入口和安全边界。

脚本自带文字、原始日志、历史更新正文、原生向导和桌面通知不在本轮翻译范围。参见[多语言支持](../多语言支持.md)。

## 安装与使用

体验包名称：`AutoScript-Hub-Preview-Setup-1.3.0-preview.2.exe`。校验值与验收结果在构建完成后记录；不要将源码分支存在视为安装包已验证。

- 手动运行独立 Preview 安装包；默认使用 `%LOCALAPPDATA%/Programs/AutoScript Hub Preview` 和 `%LOCALAPPDATA%/AutoScriptHubPreview`。
- 同一 Preview 家族沿用原 Preview 数据，安装前建议备份；不要选择正式版目录或正式数据根。
- 原生向导仍为中文；进入登录页后即可切换 English。
- 不主动读取或迁移正式版凭据。Preview 暂停在线更新，不应通过 Stable / Beta 更新入口安装本包。
- 本次不自动替换现有测试服务；连接测试服务时使用独立测试账号。
- 脚本不是沙盒，仍使用当前 Windows 用户权限。使用可信测试脚本，勿将测试参数指向正式业务文件。

更多边界见 [Preview 安装与数据隔离](../Preview安装与数据隔离.md)。
