# AutoScript Hub 1.2.3-beta.1

这是供 Beta 更新通道验证的预览版本，不会推送给 Stable 通道。

## 更新流程改进

- 版本检查仅访问 Gitee Release，避免 GitHub API 在国内网络不可达时拖慢检查或产生误导错误。
- GitHub 完整安装包仍作为下载阶段的最终兜底，但不参与版本检查。
- 点击“下载并安装”后，Agent 在独立后台线程中执行下载、续传、校验和分卷合并，本地接口立即返回。
- Agent 本地服务支持并发请求，更新下载期间继续响应连接状态及其他本地接口。
- 设置页面每秒刷新下载状态，不再把繁忙的 Agent 误判为非 Windows 客户端。
- 下载完成后仍由独立 `AutoScriptUpdater.exe` 执行静默安装、自动重启和启动失败回滚。

## 验证重点

1. 检查更新是否能在数秒内完成。
2. 点击下载安装后页面是否持续显示“正在后台下载并验证更新”。
3. 下载期间客户端其他页面是否仍可正常使用。
4. 下载完成后客户端是否自动静默安装并重启。
5. 重启后已安装版本是否显示为 `1.2.3-beta.1`。

只有预览验证通过并获得明确确认后，才会发布后续正式版本。
