# v1.2.5：脚本浏览器选择与市场删除

本版本提供脚本参数浏览器选择、管理员市场删除及本机端口独占修复。发布状态以官方 Release 为准；不移动或替换已公开的 v1.2.4 Tag 与资产。

## 变更范围

### 脚本参数选择浏览器

- 在脚本参数表单查询当前本机客户端检测到的已安装浏览器，选择后向脚本传入可执行文件路径；不修改系统默认配置。
- 使用向后兼容的静态参数定义：`type: "text"` 配合 `widget: "browser"`。不在 `config()` 中运行检测逻辑，也不新增旧客户端不能解析的参数类型。
- 默认空值由脚本回退到平台默认配置；保留手动输入、历史参数及预设，支持检测失败重试与离线提示。
- 旧客户端忽略展示元数据，继续显示文本输入并解析脚本依赖；只有新客户端具备动态选择界面。
- 浏览器检测只说明存在安装，不保证可启动或兼容脚本。脚本需要适配参数定义，客户端升级不会擅自改写市场脚本。

### 管理员删除市场脚本

- 在脚本管理页提供独立于个人卸载的市场删除操作；仅管理员可用，要求输入脚本名称确认。
- 服务端软删除，保留历史运行、工单、脚本版本和相关文件，不进行物理清理。
- 有等待中或执行中的任务时拒绝删除；不自动取消或终止任务。
- 删除与新建在线执行需串行化，避免删除检查后又插入新的等待任务。
- 删除后市场和管理列表不可见，不允许新的安装、下载或在线执行。
- 已下载文件不远程擦除，离线客户端的授权变化仍遵循既有同步与快照有效期机制；不声称离线立即撤权。

### 参数表单与删除交互

- 参数标签与控件左右对齐，说明收进问号，支持悬停与键盘聚焦查看。
- 浏览器手动输入入口与选择框同行，不再常驻显示冗长路径和说明。
- 浏览器列表固定向下展开，按可用空间限制高度并支持内部滚动，避免检测结果加载后反复翻到上方。
- 删除确认框中的脚本名可以选中复制，不额外增加提示或按钮。
- 后续纯 UI 调整优先更新前端资源，不要求重新安装客户端；本次客户端更新包含独占监听等原生功能修复。

### 本机端口独占修复

- review.1 冻结验收发现 Windows 允许旧 HTTPServer 的 `SO_REUSEADDR` 造成多个 Agent 同时监听一个端口；仅确认某个 PID 拥有监听不足以确认请求归属。
- Agent 与桌面 UI 改用独占监听，Windows 设置 `SO_EXCLUSIVEADDRUSE`，禁止地址与端口复用。占用时保留既有备用端口行为，不抢占其他进程。
- 使用临时随机端口验证新/旧服务互相不能共用监听；针对性回归 17 项通过。修复后以 review.2 重新完整构建及验收，不替换 review.1 证据。

## 不包含

- 不合并此前误做的系统设置浏览器选择分支。
- 不引入 1.3.0 Preview 的调度、机器人或本机闹钟功能。
- 不自动删除任何真实市场脚本，不迁移或覆盖 Preview 安装与数据。
