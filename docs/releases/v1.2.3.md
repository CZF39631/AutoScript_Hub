# AutoScript Hub 1.2.3

## 客户端更新

- 版本检查优先访问当前服务器缓存并回退 Gitee，不访问 GitHub API。
- GitHub 完整安装包保留为已签名清单中的公开下载兜底。
- 点击下载安装后由 Agent 后台执行下载、续传、校验和合并，本地服务在下载期间保持响应。
- 修复检查完成且暂无更新时，页面刷新后重新显示“尚未检查”的问题。
- 支持 `review` 本地版本参与更新比较，可在正式发布前完整验证更新链路。
- 下载验证完成后继续由独立 `AutoScriptUpdater.exe` 静默安装、重启和回滚。

## 服务器更新缓存

- 服务端可在启动后立即、随后按默认每 6 小时检查 GitHub Release。
- 分别验签和缓存 Stable/Beta Windows 安装包，完整校验大小与 SHA-256 后原子发布。
- 管理员 API 可启停缓存并配置服务器出站代理、GitHub 仓库和检查周期。
- 客户端优先从所连接服务器下载缓存安装包，缓存缺失或旧服务器不支持时自动回退公开源。
- 新版本停止生成 Gitee 安装包分卷；Gitee 只镜像签名清单，完整安装包由 GitHub 托管。

## 界面与构建

- 应用 Air Hub 图标，统一网页 Favicon、登录页、侧边栏、Windows 程序、更新器、安装器和快捷方式。
- 修复完整构建测试可能向开发电脑发送模拟脚本失败通知的问题。

## 服务端配置

服务端自动缓存默认关闭。升级后管理员可调用 `PUT /api/settings/server-update` 启用；具体请求格式见 `docs/0.9-deployment-runbook.md`。
