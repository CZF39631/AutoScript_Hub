# AutoScript Hub 1.2.3-beta.2

这是供 Beta 更新通道验证的预发布版本，不会推送给 Stable 通道。

## 修复

- 更新检查完成且暂无可用更新时，持久化检查到的最新版本；页面刷新或状态轮询后不再错误显示“尚未检查”。
- 支持 `1.2.2-review.1`、`1.2.3-beta.2-review.1` 等仅用于本地预览的 Review 版本参与更新比较，无需创建线上 Tag 或 Release。
- 客户端测试统一屏蔽真实桌面通知，并使用带有效 PID 的模拟进程，避免本地构建期间弹出模拟脚本失败通知。

## 继承自 Beta.1

- 版本检查仅访问 Gitee Release，GitHub 完整安装包仅作为下载兜底。
- Agent 后台异步下载、续传、校验和合并更新包，本地服务在下载期间保持响应。
- 下载完成后由独立 `AutoScriptUpdater.exe` 静默安装、重启和回滚。

## 验证重点

1. 从 `1.2.3-beta.1` 检查并升级到 `1.2.3-beta.2`。
2. 升级期间客户端保持在线，页面持续刷新下载状态。
3. 在 Stable 通道检查后显示最新 Stable 版本和“当前已是最新版本”，刷新页面后状态不丢失。
4. 操作审计页面正常加载。
