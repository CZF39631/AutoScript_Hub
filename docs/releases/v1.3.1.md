# v1.3.1：设备托管与被控模式

`v1.3.0` 的自动发布在 Windows 安装包上传前因预览版文件名不符合正式发布契约而中止，未创建 GitHub/Gitee Release。根据不可移动公开 Tag 的规则，本次修正使用新版本 `v1.3.1`，恢复正式安装包的既有 AppId、安装目录、数据目录和 `AutoScript-Hub-Setup-<版本>.exe` 命名；不覆盖或移动 `v1.3.0` Tag。

本版本新增中心化设备托管能力。管理员可以在不开放被控电脑入站端口的前提下，统一查看设备状态、下发临时任务、维护固定间隔或 Cron 计划，并在明确的隐私边界内按需查看低频屏幕缩略图。

## 设备托管

- 客户端新增被控模式与独立设备身份，管理端可查看在线、离线、停用、当前任务、最近结果和计划状态。
- 支持设备搜索、筛选、服务端分页、分组及批量发布、暂停接单、恢复接单、暂停计划和调整分组。
- 设备正在运行任务时禁止重复发布临时任务；前端禁用，服务端同时返回 `409` 强制保护。
- 停用与删除前展示受影响任务和计划，使用并发版本校验避免基于过期预览执行危险操作。
- 删除后的设备身份不会仅凭同一 `device_uid` 自动恢复，重新接入必须重新授权。

## 临时任务与定时计划

- 从设备卡片的统一“发布任务”入口创建临时任务、固定间隔计划或五段 Cron 计划。
- Cron 默认使用 `Asia/Shanghai` 时区；服务停机期间不补发历史积压，从恢复后的当前时间计算下一次执行。
- 支持计划编辑、暂停、恢复、立即运行、删除、最近运行结果及短月份执行提示。
- 支持任务结果查看和失败任务重试，并记录原始运行与重试运行的关联关系。
- 调度、取消和批量操作均使用持久化状态、幂等键与租约；中断或页面刷新后可识别 `processing`、`stale` 并安全续跑。

## 屏幕缩略图与隐私

- 仅被控模式采集，每 60 秒最多上传一张 JPEG；最长边 `1280px`、默认质量 `82`、最大 `1 MiB`。
- 服务端每台设备只保留最新一张并原子覆盖，不保存历史画面。
- 锁屏或无法确认交互桌面状态时不采集；截图失败不影响心跳、任务执行或日志上传。
- 首次启用被控模式必须明确知情同意；被控端可随时暂停采集，暂停后服务端同步清除已有缩略图。
- 缩略图不随设备列表自动批量下载，仅管理员明确查看时按需读取，并记录设备、操作者及上下文审计。
- 上传同时校验用户 JWT 与 `X-Agent-Token`，避免仅持有单一凭据即可写入设备画面。

## 规模化管理与恢复

- 批量任务逐项持久化执行结果，可重入、可审计，不因单台设备失败丢失整个批次进度。
- 服务端租约避免多个恢复者重复处理同一批次；原幂等键可用于继续未完成批次。
- 前端通过 `sessionStorage` 保存待恢复批次，刷新后继续轮询，终态后自动清理。
- 补充托管设备列表、计划与批次相关查询索引，并增加设备级审计上下文。

## 数据库迁移

升级服务端会依次应用以下迁移：

- `0006_managed_agent_mode`
- `0007_agent_thumbnails`
- `0008_managed_schedule_cron`
- `0009_run_retry_lineage`
- `0010_agent_thumbnail_capture_pause`
- `0011_managed_agent_scale`
- `0012_managed_schedule_missed`
- `0013_managed_batch_recovery`

升级前必须使用标准运维流程完成 SQLite 在线备份，并在升级后确认 `/api/health/ready` 中 `database`、`data_dir` 和 `migration` 均为 `ok`。

## 已知边界

- 本版本提供低频静态缩略图，不包含实时视频监看；后续实时能力将单独评估 WebRTC P2P。
- 被控电脑不开放管理端口，所有心跳、任务领取、结果和缩略图均由客户端主动连接中心服务。
- 本版本不包含 Apple/macOS 风格 UI 实验分支的改动，继续使用已完成业务验收的设备托管界面。
- 当前能力适用于私有部署和中小团队托管，不承诺大型企业 SLA、标准 SSO、审批流、防篡改审计或强沙箱。
