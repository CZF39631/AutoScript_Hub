# AutoScript Hub 1.2.4

本版本基于用户已验收的 `1.2.4-review.2`，发布为 Stable 正式版。

## 执行与环境

- 在线任务使用创建时锁定的脚本版本，避免排队期间发布新版导致记录与实际执行不一致。
- 离线历史取得后端 ID 后立即保存，领取、日志或状态回写中断时复用同一记录；日志失败仍尝试回写终态，避免长期占用执行名额。
- 本地和在线执行共用启动互斥；每个子进程使用独立参数文件，启动失败时清理临时文件。
- 修复自定义环境变量的反序列化顺序，恢复环境创建、更新、列表、详情与默认环境接口。

## 工单与更新恢复

- 异常历史参数显示提示和原始文本，不再造成页面白屏。
- 快速切换或关闭工单时忽略旧日志响应，防止显示另一张工单的日志。
- 工单长文本、路径及解决说明在弹窗内换行，标签保持可读。
- 更新器验证启动阶段保留进程归属；异常退出后解除陈旧状态锁定，不干扰仍在运行的更新器。

## 安装与连接兼容

- 覆盖安装检测目标目录的旧客户端和 Agent，并明确询问是否关闭，默认选择“否”。
- 先停止客户端守护，再停止 Agent 及其脚本子进程；确认退出后才替换文件，失败时阻止继续复制。
- 不再按进程名全局结束 Agent；静默安装遇到旧进程时需要显式允许关闭应用。
- UI 和 Agent 默认端口冲突时使用备用端口，前端支持发现 Agent。
- Agent 意外退出后客户端尝试重启并恢复连接。
- 托管 Python 环境默认使用清华 PyPI 镜像。

## 升级说明

- 本轮含客户端和服务端修改；环境接口修复需要服务端升级到 `1.2.4`。
- 安装前保存工作并停止业务任务；同意关闭应用会中断 Agent 下的脚本子进程。
- 继续采用签名更新清单、文件长度及 SHA-256 校验。GitHub 是安装包真源，Gitee 镜像代码、部署包、Skill、签名清单及校验资产。
- 不包含后续规划中的诊断包、统一脱敏、定时调度、编辑器、AI 或沙箱。

## 验收依据

- Review 2 用户验收已确认。
- 预览构建通过 Python 412 项与前端 26 项测试，安装器共享关闭代码实际编译及只读进程识别通过。
- 本机隔离覆盖测试曾因临时合成 EXE 启动被拒绝而受阻；用户验收不等同于该自动化测试通过。正式发布仍由 CI 重跑测试、安装冒烟及双架构镜像验证。
