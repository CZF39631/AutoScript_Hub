# AutoScript Hub 1.2.1-beta.2

这是供 Beta 更新通道使用的预览版本。

## 修复与改进

- 发现新版本后持久化保存已验证的签名更新清单，刷新页面或重启客户端后无需重复检查即可继续下载安装。
- 更新源暂时超时或不可用时，不再清除已经发现的新版本。
- 后台周期检查仍会发现并替换为更高版本。
- 修复客户端检查更新沿用本地 API 10 秒超时，网络较慢时误报 `timeout of 10000ms exceeded` 的问题。
- 包含 Windows 维护电脑发起远程服务器升级时的兼容修复。

## 更新方式

在客户端系统设置中将更新通道切换为 **Beta（测试版及稳定版）**，保存并等待客户端同步设置后，再点击“检查更新”。

本预览版不会推送给 Stable 更新通道。
