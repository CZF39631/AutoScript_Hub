# AutoScript Hub 1.2.4 Review 1

## 发布定位

本版本为 `1.2.4-review.1` 本地预览，不创建或推送 Tag，不上传 GitHub/Gitee Release，也不替换已公开正式资产。通过本地验收后，另行确认 Beta 或正式发布。

## 本轮修复

- 在线任务执行创建时锁定的脚本版本，不再使用领取时市场最新版本；缺少有效版本时明确失败，不静默换版。
- 离线运行记录在取得后端 ID 后立即保存；日志、领取响应或最终状态回写失败后续传同一记录，不重复新建。
- 日志补传失败仍尝试上报完成状态，避免已完成的离线任务长期占用在线执行名额；补传前检查记录所属 Agent。
- 本地和在线启动共用互斥入口，防止恢复联网或依赖准备期间启动第二个任务；子进程参数文件独立，避免覆盖。
- 修复自定义环境变量在响应校验前未反序列化，导致保存后环境列表、详情及默认环境接口失败的问题。
- 工单历史参数解析失败时显示提示，不再导致整个页面白屏。
- 切换或关闭工单时忽略过期日志响应，避免日志与工单不匹配。
- 更新验证阶段保留更新器进程归属，补齐异常退出后的状态恢复，防止后续更新检查卡死。

## 已合入的兼容修复

- 工单详情长文本、长路径和解决说明自动换行。
- UI 与 Agent 默认端口被占用时尝试备用端口，并支持前端发现。
- Agent 意外退出后由客户端尝试恢复连接。
- 内置 Python 环境默认使用清华 PyPI 镜像。

## 验收重点

- 自定义环境变量创建、修改为空对象、查询列表与详情。
- 创建任务后发布新脚本版本，确认实际执行仍使用原锁定版本。
- 本地任务运行及依赖准备期间，在线/本地入口不得并发启动第二个任务。
- 离线同步在日志和状态回写中断后恢复，确认仅复用同一后端记录。
- 异常历史 JSON、快速切换工单、长文本弹窗的开发模式浏览器回归。
- 活更新器不会被抢占，已退出更新器的验证状态可恢复；安装启动失败提供明确错误。
- 本地安装包版本、独立 Python Runtime、UI 与 Agent 启动冒烟。

## 范围说明

- 本轮为缺陷修复，不包含工单诊断包、统一脱敏、定时调度、内置编辑器、AI 或沙箱等后续规划。
- 客户端与服务端都有修改；仅安装客户端不会修复旧服务器的环境接口。
- 离线同步继续使用现有 API；取得后端 ID 前的创建响应丢失不属于完整端到端幂等保证，后续可通过专用历史导入接口完善。
