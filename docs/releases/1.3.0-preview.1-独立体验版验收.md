# 1.3.0-preview.1 独立体验版验收

## 版本边界

本次按用户要求明确区分安装家族：**Stable / Beta / RC 共用原安装身份和用户数据；仅明确 Preview 版本是独立开发体验版**。不以 beta 渠道或 `is_prerelease` 代替安装身份判断。

- Preview：独立 AppId、安装目录、快捷方式和 `%LOCALAPPDATA%/AutoScriptHubPreview` 数据根。
- 独立 token、WebView 数据、Agent/UI 端口；不读取旧安装目录配置，不继承正式应用的服务/脚本/日志目录环境配置。
- 拒绝接管未标识的已有数据及跨身份安装目录；安装身份验证先于停止进程。
- Preview 在线更新暂禁，避免旧签名清单缺少安装身份字段而跨身份安装；正式 Beta/Stable 更新语义保留。

详见 [安装与数据隔离](../Preview安装与数据隔离.md)。
