## 内容

包含第二、三阶段的诊断、安全执行、本机/远程调度，以及 Agent 主动 WS 通知通道。WS 只唤醒原 HTTP 对账，不绕过授权、领取、唯一启动确认、停止报告和持久化重试。保留原轮询，支持退避重连、凭据代际隔离、75 秒静默连接重建、有限帧和连接配额。

服务端按已提交状态的有界快照提示变化，适用于当前单实例；不声称零延迟推送或无限设备规模。

## 验证结果

- 在不含根目录私有 config.json 的独立源码快照和 Python 3.11.9 venv 中构建，依赖未安装到维护电脑全局解释器。
- 完整 Python 测试：**627 passed**，128.38 秒；没有扫描仓库根 `tmp/`。
- 前端 **38 passed**，ESLint、Vite 构建通过。
- 真实 loopback Uvicorn + websocket-client：握手 101、提交后的变更通知、设备凭据失效关闭通过；其他异常恢复、认证和限额由隔离测试覆盖。
- 最终冻结 Agent 的临时安装布局验证：版本 `1.3.0-preview.1`、私有 Python `3.11.9`、真实环境预热、multiprocessing prepare、合成脚本成功；未缓存依赖的离线负例失败且不执行；本次进程树清理已确认。
- 冻结验收首次发现本机接口 401；Windows 默认地址复用可能让多个 Agent 共享端口。增加独占绑定、冲突回退及验收端口唯一所有权检查后，重新完整构建并通过上述冻结测试。没有执行 Setup 覆盖安装或终止现有客户端进程。
- 构建工具：CPython 3.11.9、PyInstaller 6.11.1、Node 24.16.0。Node 与 CI 的 20 版本不同，已记录；仍有框架弃用、前端大包和 Inno 旧函数名称提示。
- 构建时源码逐文件 SHA-256 清单随包保存；完成构建后核对工作树源码与快照一致。

## 使用与未覆盖事项

1. 测试新任务和 WS 必须有配套 1.3.0 测试服务端；只安装客户端不会让生产 1.2.4 获得新接口。服务端应使用独立数据库、数据卷和端口，不复用生产部署配置。
2. 安装器沿用正式 AppId 和默认用户数据目录，可能升级已有客户端；不能把选择临时安装路径当成数据隔离。建议在测试 Windows 用户或 VM 安装，先保留原版本安装包和数据备份。
3. 未执行真实 Setup 覆盖安装、企业 WSS 证书/反向代理验收或真实双设备业务试运行；服务端源码包未构建为镜像。上述测试不得替代这些验收。
4. 脚本仍以目标 Windows 用户权限运行，不是安全沙箱，没有 CPU/内存硬配额。旧 pending 与 unknown 结果需要人工核对，不自动重跑。
5. preview.1 被版本比较库视为 rc.1，高于同版本 beta、低于正式 1.3.0。
6. 本次没有合并、推送、Tag、远程发布或生产升级。
