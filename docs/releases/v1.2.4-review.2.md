# AutoScript Hub 1.2.4 Review 2

本地预览版 `1.2.4-review.2`，保留 [Review 1](v1.2.4-review.1.md) 的执行、环境、工单及更新恢复修复。旧预览包保留，不创建线上 Tag 或 Release，不覆盖已公开资产。

## 覆盖安装修复

- 安装前按目标安装目录检测旧客户端和 Agent，不再按进程名全局结束程序。
- 交互安装发现旧进程后，提示关闭会中断脚本，询问是否关闭后继续，默认选择“否”。
- 先停止客户端以消除 Agent 守护重启，再停止 Agent 及其脚本子进程。
- 检查关闭命令结果并重新查询进程，确认退出才允许替换文件；失败时停留在安装准备阶段并给出重试提示。
- 无法获取进程路径时保守阻止安装，不猜测进程归属。
- 静默安装有旧进程时要求明确的 `/CLOSEAPPLICATIONS` 或 `/FORCECLOSEAPPLICATIONS`；`/NOCLOSEAPPLICATIONS` 始终禁止自动结束进程。
- 保留 Inno Setup 原有 `CloseApplications=yes`，继续处理其他占用文件的程序。

## 验收要求

- 旧 UI 与 Agent 均运行并有守护拉起时，确认关闭后可以完成覆盖安装。
- 拒绝关闭时不终止旧程序、不替换文件。
- 另一个安装目录的同名程序不受影响。
- 关闭失败或进程路径检查失败时不得忽略错误继续复制。
- 使用独立测试 AppId 和临时目录做安装器回归，不修改真实客户端安装注册项或用户数据。
