# 被控模式与托管计划

## 功能概览

被控模式用于让一台 Windows 电脑以精简界面持续连接 AutoScript Hub，并接收管理员定向下发的一次性任务或固定间隔托管计划。

```text
管理端 → AutoScript Hub 服务端 ← 被控电脑 Agent
```

被控电脑不开放远程监听端口。任务、状态、日志和审计均经过中心服务端。

## 启用被控模式

首次安装客户端时，在安装向导中选择“被控模式”。已有客户端也可以在本机配置中将 `client_mode` 设置为 `managed`，重启客户端和 Agent 后生效。

被控模式保留：

- 本地 Agent 和服务端连接状态；
- 设备名称及设备标识；
- 当前任务和最近运行；
- 管理员停用提示；
- 任务开始、成功、失败和取消的系统通知。

被控模式不提供脚本管理、环境管理或本地手工执行入口，`/local/execute` 也会拒绝调用。

## 管理端操作

管理员可以从侧边栏进入：

- **被控设备**：查看在线状态、心跳和版本，启停设备，并向指定设备下发一次性任务；
- **托管计划**：创建、编辑、启停、立即执行或删除固定间隔计划。

下发任务时，脚本和执行环境均按目标设备所属用户的实际权限加载，避免选择目标设备无法访问的资源。

## 定时与离线规则

当前计划支持固定的分钟、小时或天间隔。

- 一次性任务和每次计划实例都有领取有效期；
- 设备在有效期内恢复连接，可以继续领取；
- 超过有效期的任务标记为“已过期”，不会再执行；
- 同一计划已有等待中或执行中的任务时，不继续积压新实例；
- 服务端停机期间已经超过有效期的旧批次记录为过期，不会在恢复后补跑；
- 执行中断线不会转移到其他电脑，避免具有副作用的脚本重复执行。

## 设备身份安全

- 客户端首次注册会生成稳定的随机 `device_uid`；
- 被控设备还会获得绑定该 Agent 和所属用户的签名设备令牌；
- 心跳、取任务、领取、状态回写和日志上传都会验证设备令牌；
- 同一用户下的其他电脑不能冒充目标 Agent 领取定向任务；
- 管理员停用设备时，其等待任务会取消，运行任务会失败结束；
- 设备令牌不得写入日志或提交到仓库。

## 权限与审计

只有 `admin` 可以：

- 查看全部被控设备；
- 启停设备；
- 定向下发任务；
- 管理托管计划。

设备注册、任务下发、设备启停、计划创建和修改、计划物化、任务取消或过期等操作均进入审计记录。审计只记录资源 ID、版本和参数键等必要信息，不记录设备令牌或参数敏感值。

## 屏幕缩略图监看

被控模式在设备解锁且处于可交互桌面时，每分钟生成一张最长边不超过 1280 像素、大小不超过 1 MiB 的 JPEG 缩略图并上传到中心服务端：

- 管理端以小电脑卡片显示每台设备的最新缩略图；
- 服务端每台设备只保留最新一张，新图片原子覆盖旧图片；
- 不建立截图历史，不作为任务结果或日志归档；
- 锁屏、无法确认桌面状态或捕获失败时不采集、不上传；
- 被控端精简面板持续展示采集规则，不能静默隐藏；
- 截图失败不影响任务执行、心跳或日志回传。

该能力仅用于低频状态确认，不是视频流，不采集声音，也不提供键鼠控制。

## 后期能力：P2P 视频流

实时视频流暂不进入初期版本。后续如实施，优先采用 `mss + aiortc + PyAV + WebRTC`：中心服务端仅承担鉴权和信令，媒体优先 P2P，必要时使用 coturn 兜底。实施前需单独评估持续授权提示、会话审计、NAT 穿透、带宽、并发和隐私策略；不得通过提高静态截图频率伪装成视频流。

## 当前边界

当前版本暂不包含：

- 任意 Cron 表达式、节假日和复杂日历；
- 设备组批量广播；
- 实时视频、录屏、声音采集或远程键鼠控制；
- 任意 PowerShell/Shell 远程执行；
- 被控电脑结果文件的跨设备下载；
- 执行中任务迁移或自动重跑。

这些限制用于保证首版任务调度可预测且便于审计。
