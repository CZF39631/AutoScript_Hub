# 被控模式与托管计划

## 功能概览

被控模式让 Windows 客户端持续连接 AutoScript Hub，只执行管理员定向下发的任务和托管计划。

```text
管理端 → AutoScript Hub 服务端 ← 被控电脑 Agent
```

被控电脑不开放远程监听端口。任务、状态、日志、屏幕缩略图和审计均经过中心服务端；被控模式不提供脚本管理、环境管理或本地手工执行入口，`/local/execute` 也会拒绝调用。

## 首次启用与迁移

首次安装时可在向导中选择“被控模式”。在进入后续步骤前，向导会明确披露并要求本机用户显式同意：

- 设备解锁时最多每 60 秒截取一张低分辨率屏幕缩略图；
- 缩略图上传到中心服务端，管理员可以查看；
- 每台设备只保留最新一张，不保存截图历史；
- 本机可以随时暂停，暂停后不再截图或上传，并请求服务端清除现有最新缩略图；
- 不采集声音，不提供键鼠控制，采集或上传失败不影响心跳和任务执行。

未显式同意时，新的配置默认写入 `thumbnail_capture_paused=true`，Agent 不会采集。向导不会在未同意的情况下完成被控模式启用。

已有配置继续兼容：升级前已经处于被控模式且没有该字段的配置，保留旧版本原有的采集行为；新安装、从标准模式新切换或显式保存但缺少该字段的被控配置采用暂停默认值。设备身份、任务和计划数据不因升级而重建。

## 设备身份与安全

- 首次注册生成稳定随机的 `device_uid`；
- 被控设备获得绑定 Agent 和所属用户的签名设备令牌；
- 心跳、取任务、领取、状态回写、日志和缩略图上传同时验证用户凭据与设备令牌；
- 同一用户的其他电脑不能冒充目标设备领取定向任务；
- 管理员停用设备时，等待任务取消、运行任务进入取消状态，启用计划暂停；
- 设备令牌不得写入日志或提交到仓库。

## 管理端现有能力

### 设备与分组

“被控设备”页面支持分页、搜索、状态/任务状态/设备组筛选及排序。管理员可以：

- 查看连接、心跳、当前任务、待领取数和最近结果；
- 暂停或恢复接单，查看影响后删除设备；
- 向单台设备下发临时任务，查看并维护该设备的托管计划；
- 创建设备组、调整成员，并按设备组筛选；
- 选择本页设备或当前全部筛选结果，批量发布任务、暂停/恢复接单、暂停计划或调整分组。

批量操作有单批上限：发布任务最多 50 台，其他操作最多 200 台。执行前可预览逐设备结果。执行使用幂等键，逐项落库；中断后 GET 可读取部分进度，同一幂等键会在租约释放或过期后继续未处理项，已完成项不会重复执行。当前执行状态使用 `processing`、可恢复的 `stale` 和 `completed`；`processing` 由短租约防止两个请求同时处理同一批次。

### 托管计划

计划同时支持：

- 固定间隔：最短 60 秒；
- Cron：标准五段表达式（分钟、小时、日、月、星期）和 IANA 时区；
- 可视化的每日、每周、每月模式，以及高级 Cron 输入；
- 启停、编辑、立即执行和删除。

Cron 按计划时区计算下次触发。日期与星期字段同时受限时遵循 Cron 的 OR 语义。每月 29—31 日遇到不存在的日期会跳过该月，并在管理端显示最近一次错过原因。

## 调度、离线与重复保护

- 一次性任务和每次计划实例都有领取有效期；
- 设备在有效期内恢复连接可以继续领取；
- 超过有效期的任务标记为“已过期”，不再执行；
- 同一计划已有等待中或执行中的任务时，不积压新实例；
- 服务端停机期间已越过原有效期的触发记录为错过，不在恢复后补跑；
- 未越过有效期的最近一次到期计划可按当前调度规则物化；
- 执行中断线不会转移到其他电脑，也不会自动重跑，以免有副作用的脚本重复执行。

脚本和执行环境始终按目标设备所属用户的实际权限校验。

## 屏幕缩略图与本机暂停

设备解锁且桌面可交互时，Agent 最多每 60 秒生成一张 JPEG：最长边不超过 1280 像素，文件不超过 1 MiB。服务端原子覆盖上一张，仅保存最新文件和更新时间/大小元数据。

本机暂停优先于管理员设置：

1. 本机持久化 `thumbnail_capture_paused=true`；
2. 采集线程在截图前和上传前都检查该状态；
3. 后续心跳携带暂停状态，服务端立即令现有缩略图不可查看并尝试删除文件；
4. 文件清理失败会记录服务端告警并由后续心跳重试，但不会让心跳失败；
5. 只有本机可以恢复采集，管理员不能远程绕过。

锁屏、桌面切换、截图或上传失败均不影响任务轮询、心跳、日志和任务状态。该能力不是视频流，不录屏、不采集声音，也不提供远程控制。

## 权限与审计

仅 `admin` 可以查看全部被控设备、查看最新缩略图、管理设备和计划、执行批量操作。缩略图查看、设备启停/删除、分组调整、任务下发、计划变更和批量执行均写入审计日志。审计页面会显式显示当前对象筛选、设备名称和清除筛选入口；审计详情不记录设备令牌或参数敏感值。

## 当前边界

当前版本不包含：

- 节假日日历或 Quartz 秒/年字段；
- 实时视频、录屏、声音采集或远程键鼠控制；
- 任意 PowerShell/Shell 远程执行；
- 被控电脑结果文件的跨设备下载；
- 执行中任务迁移或自动重跑。

实时视频如后续实施，应单独评估持续授权提示、会话审计、NAT 穿透、带宽、并发和隐私策略，不得通过提高静态截图频率替代视频方案。
